# PS

백준(BOJ)과 Codeforces 문제 풀이를 모은 C++ 저장소입니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| [BOJ/](BOJ/) | 643개 문제의 C++ 소스 654개 |
| [Codeforces/](Codeforces/) | 7개 대회 폴더의 C++ 소스 40개 |
| [archive/vscode/](archive/vscode/) | 과거 VS Code 설정 |

## 파일 구조

- BOJ: `BOJ/<문제 번호>/<문제 번호>.cpp`
- Codeforces: `Codeforces/<대회 폴더>/<문제 번호>.cpp` (예: `CF690/E1.cpp`)
- 같은 문제의 풀이가 여러 개 있으면 파일명 접미사(`_dp`, `_fenwick`, `_2` 등) 또는 하위 폴더로 구분합니다.
- `root`, `old20_1` 등의 하위 폴더명은 소스의 이전 저장 위치를 나타냅니다.
